# Kickoff prompts

- `template.md`: the generic three-phase template (A: design chat, B: implementation, C: grading)
- `WS-02.md` … `WS-05.md`, `WS-11.md`: Phase A design kickoffs for the core workstreams and force design. Run them in the claude.ai Project. Each produces an approved spec that its Phase B implementation prompt builds on.

Order: WS-02 → (WS-03 ∥ WS-04) → WS-05 → WS-11. Prompts for WS-06 to WS-09 will be written after the core specs are approved (WS-07 right after WS-11).
