# M4 — Sim-core skeleton · Phase B implementation prompts

Implements WS-02 v1.3 (Approved): ARC-001 to ARC-100. Run it as **six increments, one Claude Code session and one PR each**, in this order. Each PR must be green, and graded, before the next one starts. A single giant PR would blow through usage limits and be ungradeable.

Model: Opus, medium effort, for M4a–M4c (determinism and commit semantics are subtle); Sonnet, medium effort, for M4d–M4f. Grader: Opus on M4b and M4c, Sonnet on the rest.

| Inc | Scope | Requirements |
|---|---|---|
| M4a | Cargo workspace, toolchain pin (`rust-toolchain.toml`), dependency allowlist, clippy bans, CI workflow (fmt, clippy, test, dependency checks), Tauri hello-world stub | ARC-001–004, ARC-100 |
| M4b | World state model, truth/belief types, graphs, tick pipeline with stage-end commit, order validation, NaN guard, stub subsystems (`stubs.rs`, test feature) | ARC-010–016, ARC-020–024 |
| M4c | RNG factory and golden values; `Tracked`/breakdown types, the explain API, the snapshot ring, lazy unit breakdowns | ARC-030–034, ARC-040–046 |
| M4d | Content loading and validation. Port `prototypes/ws08a-content-check` (types and `wld_*` tests, keeping their names), then delete the prototype. Load WS-08b Sol and resource content per WS-02 §6. | ARC-050–053, the WLD tests marked M4 in WS-08a/08b |
| M4e | Save/load, input log, replay, state hash; CI double-run hash comparison | ARC-060–063 |
| M4f | CLI (`run`, `batch`, `export`, `bench`), fidelity tiers with conservation, the ARC-090 bench scenario and CI threshold | ARC-070–072, ARC-080–082, ARC-090–091 |

Check that the ranges above still match WS-02 §4 before starting. If they've drifted, the spec wins.

**M4b notes:**
- WS-05 P-02a is applied in WS-02 v1.3 (ARC-016: per-subsystem `SubjectIdx` ranges in a fixed order, and a polity may omit a range, so lookups there return `None`). Build the belief store with this from the start.
- ARC-016(a) and ARC-010 use the minimal test setting in `crates/sim-core/tests/content/`. Use only as much loader as they need. If the shuffled-content part of ARC-016(a) needs the full ARC-053 index rules, grade it PARTIAL and finish it in M4d.
- `rnd`, `econ`, `gov`, `force`, `resources` and `space` stay stubs until M5/M6.
